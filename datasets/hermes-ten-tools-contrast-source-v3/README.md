# 도구 경계 대조 학습 원문 v3

Codex가 새로 작성한 한국어 합성 학습 사례 200개다. 10개 도구 각각 20개이며, 이전 데이터의 validation/test 문장을 변형해 만들지 않았다. 원문은 `cases.jsonl`, 출처와 해시는 `manifest.json`, 중복 검사와 편집 내역은 `audit.json`에 있다.

| 구성 | 사례 수 | 시나리오 수 |
|---|---:|---:|
| 문서 읽기·파일관리 ↔ 본문 수정 | 40 | 20 |
| 계좌 현황 조회 ↔ 모의 주문 실행 | 40 | 20 |
| 과거 종가 이력 ↔ 현재 시세 | 40 | 20 |
| Bases 설정·뷰 ↔ Dataview DQL | 40 | 20 |
| 링크·태그 관계 탐색 | 20 | 20 |
| 과거 RSI 전략 검증 | 20 | 20 |
| 합계 | **200** | **120** |

문맥이 있는 사례는 24개다. 같은 상황에서 다른 의도를 묻는 두 문장은 같은 scenario_id로 묶었으므로, 80개 시나리오는 두 도구 라벨을 포함한다. 모든 사례는 train에만 추가한다. 향후 CV에서도 대조 쌍을 서로 다른 fold로 분리하면 안 된다. 기존 homogeneous-only fold 생성기는 이러한 혼합 라벨 그룹을 거부하므로 그대로 새 800개 pool에 실행하지 않는다. 일반 grouped stratification을 도입하거나 새 대조 그룹을 train-only 보강 자료로 유지하는 별도 CV 계획이 필요하다.

정답은 작성자 자체 검토와 명세·형식 검사만 거쳤다. 독립 검토자나 사람 검토 완료로 표시하지 않았으며 모든 행은 `needs_human_review`, `execution_verified=false`다. 주문 요청도 합성 문장으로만 저장했고 실제 주문을 실행하지 않았다. 기존 train600·validation20·test20에 대한 정규화/문자3-gram·단어 Jaccard 0.55 기준 근접 중복은 최종 자료에서 0건이었다. 이는 의미상 독립성이나 라벨 정확도를 보증하지 않는다.
