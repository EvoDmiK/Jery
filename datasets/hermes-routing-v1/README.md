# Hermes routing seed dataset v1

한국어 요청을 보고 **현재 후보 목록에서 다음에 사용할 도구**를 선택하는 초기 합성 데이터셋이다. 실제 대화 로그나 실행 결과를 사용하지 않았다. 정답은 도구 명세를 참고해 작성한 초안이며 전부 `needs_human_review` 상태다.

## 구성

- Hermes `hybrid-v2`의 로컬 MCP 스키마 캐시에서 추출한 도구 10개: Obsidian 4개, Swallow 5개, Kestrel 1개.
- 합성 사례 130개: 도구 선택 100개, 도구 불필요 10개, 추가 질문 10개, 후보 도구로 지원 불가 10개.
- 학습 78개, 검증 26개, 평가 26개. 원본 시나리오 65개마다 표현 변형 2개가 같은 분할에 들어간다.
- `tools.json`: 실제 도구 설명과 입력 스키마, 서버별 캐시 작성 시각, 카탈로그 버전.
- `train.jsonl`, `validation.jsonl`, `test.jsonl`: 학습·검증·평가 사례.
- `manifest.json`: 건수와 SHA-256 체크섬.

## 필드와 판단 기준

| 필드 | 의미 |
|---|---|
| `request`, `context` | 사용자 요청과 선행 대화. v1의 대화 맥락은 모두 빈 배열이다. |
| `candidate_tools` | 이 사례에서 사용 가능한 도구 ID. 명세는 `tools.json`에서 조회한다. |
| `decision` | `select_tools`, `no_tool`, `clarify`, `unsupported` 중 하나. |
| `acceptable_choices` | 허용되는 다음 선택의 목록. 각 항목의 `tool`과 선택적 `action`은 대안이며 순차 실행 계획이 아니다. |
| `scenario_id` | 표현 변형을 묶는 원본 시나리오 ID. 분할 간 섞지 않는다. |
| `review_status` | 현재 모든 사례가 사람 검토를 필요로 한다. |
| `execution_verified` | 실제 MCP 호출 검증 여부. 현재 모두 false다. |

`no_tool`은 주어진 텍스트나 일반 지식만으로 답할 수 있는 요청이다. `clarify`는 대상·변경 내용 등 필수 맥락이 빠진 요청이다. `unsupported`는 **이 데이터셋의 후보 10개**로 처리할 수 없는 요청이다. 예를 들어 모의투자 초기화와 주문은 전체 Hermes에는 도구가 있지만 이 후보 목록에는 없어 지원 불가로 분류한다.

Obsidian `vault`, `edit`, `view`, `graph`는 action에 따라 다른 작업을 수행한다. action은 보조 라벨이며 전체 호출 인자 생성이나 실행 학습은 범위 밖이다. Kestrel은 리셋 이벤트 조회용이며 개인 계정의 잔여 사용량 조회 도구로 해석하면 안 된다.

## 재생성과 검증

프로젝트 루트에서 Python 표준 라이브러리만으로 실행할 수 있다.

```sh
python3 scripts/build_seed_dataset.py
python3 scripts/validate_dataset.py
```

빌더는 저장된 `tools.json`을 사용한다. 원본 Hermes 환경에 재접속하지 않으며 기존 분할 파일과 manifest를 재생성한다. 검증은 참조 무결성, action enum, 분할 누출, 중복, 도구별 분할 커버리지와 체크섬을 확인한다. 정답의 의미적 정확성이나 서버 연결 상태를 보장하지 않는다.

## 사용 시 한계

아주 작은 시작용 데이터이며 실제 운영 정확도를 추정하기에 충분하지 않다. 후보 도구는 모든 사례에서 동일한 10개이고 맥락 의존 대화, 여러 도구 조합, 도구 실행 실패는 포함하지 않는다. 분할은 시나리오 단위로 분리했지만 같은 작업 유형과 표현 패턴이 반복되어 성능을 낙관적으로 보일 수 있다. 사람 검토와 실제 사용 사례를 보강하고, 별도의 실제 요청 평가 세트를 확보해야 한다.

도구는 실행하지 않았고 문서 본문, 계좌 데이터, 인증 토큰, 사용자 대화 로그는 수집하지 않았다. 공개 배포 전에는 도구 명세 원본의 재배포 조건을 확인해야 한다.
